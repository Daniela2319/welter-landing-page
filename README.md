# 🚜 Welter Manutenções React e Tailwind CSS

### Solução Digital para Manutenção de Máquinas Agrícolas

Landing Page institucional desenvolvida em React, com foco em presença digital estratégica para a Welter Manutenções — empresa especializada em manutenção de máquinas agrícolas e serviços gerais.

O projeto foi construído utilizando Vite e Tailwind CSS, priorizando performance, organização de código, responsividade e otimização para SEO e Open Graph.




## 📌 Visão Geral

Este projeto foi desenvolvido com foco em:

- Presença digital profissional
- Fortalecimento de marca
- Geração de leads
- Otimização para mecanismos de busca (SEO)
- Compartilhamento estratégico em redes sociais (Open Graph)

A solução apresenta os serviços da empresa de forma clara, objetiva e moderna.



## 🌾 Serviços Apresentados

- Manutenção de tratores
- Manutenção de colheitadeiras
- Equipamentos agrícolas
- Manutenção preventiva e corretiva
- Serviços gerais



## 🏗️ Arquitetura do Projeto

A aplicação foi construída utilizando uma stack moderna de Front-End:

- React
- Vite
- Tailwind CSS
- Deploy contínuo via Vercel

Estrutura baseada em componentização, garantindo:

- Organização de código
- Escalabilidade
- Manutenção facilitada
- Alta performance



## 🌐 Deploy

Ambiente de produção hospedado na Vercel:

https://welter-landing-page.vercel.app/

O deploy garante:

- HTTPS seguro
- Alta disponibilidade
- Integração contínua com GitHub



## 📊 Estratégias Implementadas

- Meta tags Open Graph para compartilhamento no WhatsApp e redes sociais
- Imagem de preview otimizada (1200x630)
- Responsividade completa (Mobile First)
- Performance otimizada com Vite
- Estrutura preparada para futuras integrações (API, formulários, etc.)



## 🚀 Execução Local

```bash
git clone https://github.com/Daniela2319/welter-landing-page.git
cd welter-landing-page
npm install
npm run dev
```
